DATA 260 HW3 Part 1 — Session Security Evidence

Valid login response

HTTP/1.1 303 See Other
location: /dashboard
vary: Cookie
set-cookie: s7838_session=<REDACTED_SIGNED_SESSION>; path=/; Max-Age=3600; HttpOnly; SameSite=Lax; Secure

Session invalidation checks

After logout:  GET /dashboard  →  /login
After timeout: GET /dashboard  →  /login?expired=true

Idle-timeout evidence used SESSION_IDLE_TIMEOUT_SECONDS=1. The normal application default remains 900 seconds (15 minutes). The signed cookie value is intentionally redacted.
