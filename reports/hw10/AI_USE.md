Separately, my first example cache-miss trace contained a 7,266 ms cache lookup because the first request after a restart loaded the embedding model. 4. I made both helpfulness prompts use the same rubric and wording, so identical text gets identical scores and the difference is exactly the change in text. I added an embedding-model warm-up when the ingress starts and re-captured the three example traces on the warm system. I added the `trace_id` argument to the stand-in pipeline's signature. I also kept the human labels out of the AI's hands: the validation script refuses to run until `human_labels.csv` is complete and committed.
